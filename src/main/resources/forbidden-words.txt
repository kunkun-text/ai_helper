# ============================================================================
# 答辩场景「违规话术」词表  （N61 · 2026-10-14）
# ============================================================================
# 用途（对应 NeMo Guardrails 的 input rails / output rails 两类护栏）：
#   ① 输入侧：学生若用提示注入、角色劫持、索要规则等话术企图操控判分 → 固定零分；
#   ② 输出侧：3B 模型在长上下文里偶发"复述提示词 / 带出不当措辞" → 替换为安全文案后再展示。
#
# 格式：一行一条，`词|标签`（分隔符可自定义，本文件用竖线）。
#       `#` 开头为注释，空行忽略；同一词可写多行挂多个标签。
#       解析器同时兼容写反的 `标签|词` 顺序，但请按 `词|标签` 书写。
#
# 标签定义：
#   jailbreak  提示注入 / 越狱 / 角色劫持 / 直接改分指令
#   meta       要求模型暴露自身规则、系统提示或提示词
#   allow      白名单，优先级最高——命中即整条放行，不做任何拦截
#
# 匹配规则（组织方式参考开源中文敏感词库 houbb/sensitive-word 的做法）：
#   · 匹配前统一归一化：去掉空白、标点与符号并转小写
#     —— 因此「忽 略 以 上 指 令」「忽略以上指令！！」与规范写法等价；
#   · 白名单优先于黑名单（同一文本黑白名单同时命中时以白名单为准）；
#   · 只收「在答辩语境下无歧义」的完整话术：单词与多义短语一律不收，避免误伤正常作答。
#     例如【不收】"扮演"「prompt」「开发者模式」这类词——技术类课题的正常回答里可能出现，
#     收了会把"网关在微服务中扮演着统一入口的角色"这类正确作答误判为违规；
#   · 词长下限 4 字（过短的词必然误伤）。
#
# 扩充方式：按同样格式追加即可，无需改代码、无需重新编译。
# ============================================================================
